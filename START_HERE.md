# 🚀 START HERE - Quick Commands

## For PowerShell Users (You are here!)

### First Time Setup:
```powershell
.\setup.ps1
```

### Run the Application:
```powershell
.\run.ps1
```

### If you get "execution policy" error:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
